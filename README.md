# GameTranslator 🎮🎧

تطبيق Windows متقدم لالتقاط ترجمة صوت الألعاب و Discord إلى العربية في الوقت الفعلي.

## المميزات ✨

- **التقاط صوت سطح المكتب**: التقط صوت من الألعاب و Discord تلقائياً
- **تحويل الكلام إلى نص**: استخدم OpenAI Whisper لتحويل الإنجليزية إلى نص بدقة عالية
- **ترجمة فورية**: ترجم النص إلى العربية باستخدام Google Translate API
- **Overlay شفاف**: عرض الترجمات في overlay شفاف فوق الألعاب
- **تحريك مخصص**: اسحب وأفلت الـ overlay في أي مكان على الشاشة
- **إعدادات قابلة للتخصيص**: تحكم بحجم الخط والشفافية والموضع

## المتطلبات 📋

- Windows 10/11 (64-bit)
- Python 3.8+
- 4GB RAM الحد الأدنى
- Internet Connection (للترجمة و Whisper)

## التثبيت والتشغيل 🚀

### 1. استخلاص الملفات
قم بفك ضغط `GameTranslator.zip`

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3. الحصول على مفاتيح API
- **Google Translate**: لا تحتاج مفتاح (الطريقة المجانية)
- **OpenAI Whisper**: متضمن محلياً

### 4. تشغيل التطبيق
```bash
python main.py
```

## الاستخدام 🎯

1. شغّل التطبيق - ستفتح نافذة التحكم
2. اضغط **"Start Recording"** لبدء التقاط الصوت
3. العب لعبتك أو استمع إلى Discord
4. سترى الترجمات تظهر في الـ Overlay الشفاف
5. اسحب الـ Overlay لتغيير موضعه
6. اضغط **"Stop Recording"** للإيقاف

## البنية الأساسية 📁

```
GameTranslator/
├── main.py                 # نقطة الدخول الرئيسية
├── requirements.txt        # المكتبات المطلوبة
├── config.json            # إعدادات التطبيق
├── src/
│   ├── audio_capture.py   # التقاط صوت سطح المكتب
│   ├── whisper_engine.py  # تحويل الكلام إلى نص
│   ├── translator.py      # ترجمة النصوص
│   ├── overlay.py         # نافذة Overlay الشفافة
│   └── ui.py              # واجهة المستخدم الرئيسية
├── assets/
│   └── icons/            # الأيقونات
└── logs/                 # ملفات السجلات
```

## الإعدادات 🔧

عدّل `config.json` للتحكم بـ:
- دقة الترجمة
- حجم وموضع الـ Overlay
- مستوى الشفافية
- سرعة المعالجة

## استكشاف الأخطاء 🐛

- **لا يتم التقاط الصوت**: تحقق من إعدادات الصوت في Windows
- **الترجمة بطيئة**: قلل جودة الصوت في الإعدادات
- **Overlay لا يظهر**: جرب تغيير وضعية النافذة
